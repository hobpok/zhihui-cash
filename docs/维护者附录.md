# 维护者附录

普通评审者只读文档、源码并反馈即可。以下仅适用于明确获准开发的维护者。

## 本地检查

Node.js 24.x（后端测试使用内存 `node:sqlite`）。

```sh
npm ci --ignore-scripts
npm test
npm run test:collaboration
npm run build:cloudflare
npm start
```

静态预览默认仅监听127.0.0.1:8769，只按构建清单提供文件；API不可用时进入匿名本地模式。浏览器存档不会通过Git同步。后端源码、空迁移与内存SQLite测试保留供评审，不包含可用生产环境。

`build:cloudflare` 是历史沿用的构建命令名，仅生成 `dist/cloudflare`；不会上传。构建清单写入 `项目记录/Cloudflare发布包.json`，两者均被忽略。本快照不提供生产部署配置、账号初始化脚本或原始指标重建工具。

## 修改与共享

在独立 `codex/` 分支工作，保留他人未提交改动。完成后检查差异、运行相关测试，更新当前文档；暂存后执行 `npm run check:share`。此检查读取Git暂存区，拒绝忽略路径、异常二进制、非迁移SQL和常见凭证格式，但不替代人工内容审查。

`.gitignore` 采用明确文件白名单。新增文件应先审查，再显式加入白名单；禁止 `git add -f`。通过Pull Request评审合并，不强制推送，不从私有开发仓库合并历史。公开快照更新须重新导出审核文件，确认所有将公开的提交、作者元数据和资产都可分享。合并不触发部署。

GitHub Actions只执行依赖安装、源码测试、共享检查和静态构建，不使用生产秘密或部署任务。远端工作流是否完成以实际Actions结果为准。
