# 数据与公开范围

本仓库公开初始设定的指标和明确的合成演示，供理解与评审。它不包含真实持仓、真实交易流水或生产用户存档。

| 内容 | 入口与含义 |
|---|---|
| 当前默认数据 | `app/default-scenario.js`：五笔无预设卖券补救案例，卖券是待经理确认的计算候选 |
| 旧六笔可切换样例 | `app/default-scenario.js`：`createBankOrderInitialTemplate`保留预设卖券的三银行约束样例 |
| 原始可切换样例 | `app/original-scenario.js`：零现金九笔样例，现行规则 |
| 规则、计划与测试fixture | `app/`、`server/*.test.js`、`data/calculation/v2b/`：合成输入与固定预期，历史用例不代表当前默认场景 |
| 历史指标目录 | `app/metric-catalog.js`：102项指标名称、分类、单位及质量说明，保留未知值；不是102条完整规则 |
| 当前分析目录 | `app/analysis.js`：121项，10项已有配置、111项待补数据，与历史指标目录区分 |
| 历史结构合同 | `data/contracts/v2a/`：开发时的模拟结构示例；实际行为须结合当前源码 |
| 教程与设计图 | `tutorial/`、`docs/design/`：合成演示／历史设计辅助，不能覆盖当前业务口径 |
| 数据库迁移 | `migrations/`：空表结构与演进，不含数据库或账户种子 |

银行名称可对应现实机构，但内置金额、评级、托管资格、季度净资产、持仓和证券代码都是模拟参数，不是对这些机构的事实断言。测试中的登录名、邮箱、口令与域名是隔离测试值，不能用于真实服务。

公开整理保留指标名称和演示业务数据，移除了不必要的原始文件名、资料定位以及适用列中无法公开解释的产品代码。历史指标的 `value`、`threshold`、`formula` 未确认时仍为 `null`，适用性不由脱敏后的空字段推断。不是把缺失资料变成已确认规则。

未包含：密钥、环境文件、实际账号、个人信息、生产数据库与备份、原始Office／PDF／压缩包、资料提取层、私有配置、内部运维历史、生产调用或运行证据。本公开仓库从独立审核快照开始，不带旧开发历史。

不要把真实账户数据导入公开测试文件或上传GitHub。提出业务问题时优先沿用已有合成样例，另造最小示例也应明确标识为合成。新增文件与每次同步都需要内容和Git历史审查；自动凭证扫描无法保证识别所有未知密钥格式或业务隐私。
