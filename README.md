# 智汇现金

货币基金交易流程模拟器：把投资计划、现金头寸、银行敞口、期限指标、下达顺序与成交收付放在同一工作台中，帮助讨论“为什么可执行、为什么受限、先做什么”。所有内置金额、持仓、评级与银行参数均为合成演示。

**当前公开快照：6-0.38.0，2026-10-26。** 本次补齐6-0.30至6-0.38的代码、回归与公开说明。默认三项银行约束六笔计划（revision 2）和原始零现金九笔样例保持；新增“补救案例（未预设卖券）”，先给5笔原计划，再由计算或AI规划发现卖出广州银行存单2亿元的补救候选。新增卖券须经理明确勾选确认，加入计划后仍需重新计算、审核和手动下达。公开版供阅读、演示和提出意见，不需要 GitHub 账号。

应用版本为6-0.38.0，版本初始化标记仍为6-0.28.0。已按该标记初始化的账号不因本次升级重置；未初始化账号沿用既有一次初始化流程。本地静态演示使用浏览器存储，已有运行不会仅因刷新自动替换为新模板。选择其他样例会保留旧运行历史并新建运行。AI依据错误现在区分金额、引用、过期等原因；可恢复时展示经校验的可信工具摘要，恢复失败保留需求并说明处理方法。

## 可选：本机演示

仅阅读和提意见时可跳过。使用 Node.js 24.x：

```sh
git clone https://github.com/hobpok/zhihui-cash.git
cd zhihui-cash
npm ci --ignore-scripts
npm start
```

打开 http://127.0.0.1:8769/app/ 。默认是匿名本地演示，数据保存在当前浏览器，不提供真实 AI、云存档或生产登录。`npm start` 只启动本地静态预览，不部署。端口被占用时可设置 `PREVIEW_PORT`，不要结束别人的服务。

本项目是可交互模拟工具，不是交易系统或已完成正式制度认证的风控系统。界面中的“下达”“成交”“收付”均指模拟流程。教程与设计草图属于辅助材料；当前业务以本页所列版本、现行源码和测试为准。

维护者开发与验证流程见 [维护者附录](docs/维护者附录.md)。
