# 智汇现金

货币基金交易流程模拟器：把投资计划、现金头寸、银行敞口、期限指标、下达顺序与成交收付放在同一工作台中，帮助讨论“为什么可执行、为什么受限、先做什么”。所有内置金额、持仓、评级与银行参数均为合成演示。

**当前公开快照：6-0.41.0，2026-10-27。** 默认“AI融资案例（默认，未预设融资及卖券）”初始4笔用款计划，不预设融资或卖券；由AI规划提出新增正回购融资34亿元及卖广州银行存单2亿元的候选。新增卖券须经理明确勾选确认，加入计划后仍需重新计算、审核和手动下达。旧六笔“三项银行约束（预设卖券）”（revision 2）和原始零现金九笔仍可选。公开版供阅读、演示和提出意见，不需要 GitHub 账号。

应用版本为6-0.41.0，版本初始化标记仍为6-0.28.0。已按该标记初始化的账号不因本次升级重置；未初始化账号沿用既有一次初始化流程。**每个账号在“数据与存储→重置当前运行副本”确认后，都将本账号的初始模板及运行统一改为四笔无融资及卖券案例，不再沿用旧运行或自定义模板。** 旧运行及成交先保留历史，新副本清除交易进度和审核；本地备份／模板保存失败时不替换运行，账号不可编辑时不允许重置。此按钮只影响当前账号，不会替其他账号操作。刷新仍不自动重置；“初始数据”中也保留三套样例的显式切换。AI诊断与受校验的可信摘要恢复保持。

新默认当日正回购到期付款10亿元，另15亿元保留为未到期1天合成负债，资产525亿－负债25亿＝净资产500亿。初始业务头寸−5亿、现金比例C02＝3%；新增“一年内政府债到期比例”＝20/500＝4%，不随日内资金流出变化。当前C02达标需融资10亿；保留全部四笔用款的候选为融资34亿1天＋卖广州CD2亿，期末现金5亿、C02＝5%、C09≈85.064天。当前比例、下一笔用款和完整计划融资须分别解释。

## 可选：本机演示

仅阅读和提意见时可跳过。使用 Node.js 24.x：

```sh
git clone https://github.com/hobpok/zhihui-cash.git
cd zhihui-cash
npm ci --ignore-scripts
npm start
```

打开 http://127.0.0.1:8769/app/ 。默认是匿名本地演示，数据保存在当前浏览器，不提供真实 AI、云存档或生产登录。`npm start` 只启动本地静态预览，不部署。端口被占用时可设置 `PREVIEW_PORT`，不要结束别人的服务。

本项目是可交互模拟工具，不是交易系统或已完成正式制度认证的风控系统。界面中的“下达”“成交”“收付”均指模拟流程。教程与设计草图属于辅助材料；当前业务以本页所列版本、现行源码和测试为准。

维护者开发与验证流程见 [维护者附录](docs/维护者附录.md)。
